## انتشار روی GitHub Pages
1. در github.com یک مخزن (Repository) جدید بسازید، مثلاً `faravanio`، و آن را Public بگذارید.
2. همه فایل‌های همین پوشه (نه خود فایل zip) را در ریشه مخزن آپلود کنید: `index.html`، `manifest.json`، `sw.js`، `icon-192.png`، `icon-512.png`، `.nojekyll`، `README.md`.
3. وارد Settings، بخش Pages شوید. در Source گزینه Deploy from a branch، شاخه main و پوشه / (root) را انتخاب و Save کنید.
4. بعد از یکی دو دقیقه، آدرس بازی این شکل است: `https://USERNAME.github.io/faravanio/`

## نصب روی اندروید
آدرس را در Chrome اندروید باز کنید، منوی سه‌نقطه، سپس Install app یا Add to Home screen.

داده‌های بازیکن فقط روی همان گوشی ذخیره می‌شود.
